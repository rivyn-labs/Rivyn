# Rivyn brand assets

`rivyn-logo-dark.svg` is the canonical Rivyn logo: use it for dark, square brand placements, including the LinkedIn company profile.

Supporting approved variants:

- `rivyn-logo-transparent.svg` / `.png` for placements that supply their own dark background.
- `rivyn-logo-light.png` for light placements.
- `rivyn-app-icon.png` for app icons and small avatar-style uses.

Do not recreate or alter the mark without replacing this set deliberately.
