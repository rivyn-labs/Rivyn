System Architecture & Governance

Parse & Store Once. Detect & Query at Binary Speed.

A five-stage deterministic and AI pipeline engineered for high-throughput resilience and enterprise compliance.

STAGE 01

Drain3 Tree Ingestion

Compiled single-pass regex masks dynamically isolate UUIDs, IPs, dates, and variable payloads. Clusters infinite raw lines into stable semantic template trees at 13,000+ lines/second.

STAGE 02

Columnar Parquet Engine

Serializes structured schema into compressed Apache Parquet with dictionary encoding. Slices millions of records with zero-copy memory mapping without memory exhaustion.

STAGE 03

3-Tier ML Anomaly Detection

Combines statistical rarity scoring, Scikit-Learn Isolation Forest on multi-dimensional telemetry vectors, and Markov sequence state transition modeling.

STAGE 04

Incident Correlator

Fuses anomalies across sliding 60s temporal windows and shared topological entities (block IDs, hostnames, container IDs), compressing alert noise by up to 99.9%.

STAGE 05

Grounded AI Reasoner

RAG vector embeddings retrieve exact evidence passages. Strict JSON schema synthesis produces root-cause hypotheses citing exact log lines, preventing hallucinations.

STAGE 06

Open REST API & SDK

High-speed FastAPI backend exposes standard REST endpoints for live streaming ingest, Parquet binary stats, temporal timeline scrubbing, and incident automation.
